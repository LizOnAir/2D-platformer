# Shroom Adventure

A simple platformer game where player navigate their way to the portal to pass the level!
This is the first game I created because I wanna explore godot and make some really cool game like others!

## How to play
Use W/A/D or arrow keys to move. Navigate your way through the platform and obstacle to reach the portal to pass the level! (Currently it's only 1 level, more coming soon!) You have 3 chances, or else gameover.
